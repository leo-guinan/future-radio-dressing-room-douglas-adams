# Douglas Adams's dressing room

Everything fictional Douglas Adams has done in the Future Radio writers' room.

- `CHARACTER.md`: who Douglas is and how he behaves. The room reads this on every run.
- `bible/`: generated character bible artifacts, built by the character-bible workflow.
- `memory/notes.md`: durable notes carried into future episodes.
- `memory/viewer-notes/`: audience proposals for canon.
- `voice/`: intended voice direction; no actual ElevenLabs voice or agent is assigned.
- `history/`: one file per future writers' room run, written by the room, not by episode repos.

Episode repos never edit this repo; they project from it pinned to a commit.

The character is a fictional portrayal. His appearance supplies **no** rights clearance, license, or legal advice.

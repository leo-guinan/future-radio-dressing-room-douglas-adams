# Changing Douglas Adams

Douglas is a fictional character in Future Radio. Viewers can propose canon after watching or talking with him.

1. **Talk first.** Clone this repo, then run `npx github:leo-guinan/future-radio-character-bible chat .`. Use `/propose <your note>` to make a viewer note with context.
2. **Add a viewer note.** Create `memory/viewer-notes/YYYY-MM-DD-short-title.md`:

   ```markdown
   ---
   from: your name, handle, or anonymous
   experience: episode or conversation
   episode: E02
   ---
   What should be true about Douglas from now on?
   ```

3. **Edit `CHARACTER.md`** to propose changes to who Douglas is, his rules, or recurring conflict.

No GitHub account? Open an issue using the Viewer note form.

## Protected records

- `history/` and `history.jsonl` belong to the writers' room and must not be rewritten by contributions.
- `memory/notes.md` is append-only.
- `bible/` is generated by CI; do not edit it in pull requests.
- Fictional Douglas must never be presented as actual legal clearance or a representative of Adams's rights holders.
